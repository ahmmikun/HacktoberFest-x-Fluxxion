# Support

Thank you for using and exploring **HacktoberFest-x-Fluxxion**! We are committed to fostering a welcoming and helpful community.

---

## Getting Help

### 1. Documentation First
Before opening an issue or asking for support, please review:
- [README.md](README.md) for project overview, prerequisites, and quickstart commands.
- [CONTRIBUTING.md](CONTRIBUTING.md) for local environment setup, testing, and contribution flow.
- [SECURITY.md](SECURITY.md) if you are reporting a potential vulnerability or security flaw.

### 2. GitHub Issues
If you have found a bug or want to propose a new feature:
- Search existing [Issues](https://github.com/ahmmikun/HacktoberFest-x-Fluxxion/issues) to ensure your question or problem has not already been answered or reported.
- If not found, create a new issue using our structured templates:
  - [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md)
  - [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)

### 3. Hackathon Support & Event Inquiries
For participants of **MLH Hacktoberfest Hack Day Lahore × Fluxxion 2026**:
- **Official Event Page**: [events.mlh.com/events/15520-hacktoberfest-hack-day-lahore-x-fluxxion](https://events.mlh.com/events/15520-hacktoberfest-hack-day-lahore-x-fluxxion)
- **Challenge Page**: [Best Open-Source AI Project Challenge](https://www.mlh.com/events/hacktoberfest-hack-day-lahore-x-fluxxion/challenges/01a0d987-0c41-12ea-13ac-5b85755dc2f3)
- **Organizer**: Fluxxion ([fluxxion.dev](https://fluxxion.dev/)) in partnership with Major League Hacking (MLH) and DigitalOcean.
- On-site mentors and organizers are available at COLABS Cantt - NASTP during the event schedule to assist with questions.
